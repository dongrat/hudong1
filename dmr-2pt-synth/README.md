# AK2404 发射两点调制频率合成器仿真

用MATLAB 做的**行为级**频率合成器仿真，对象是 AK2404（数据手册 220900015-E-04）的发射两点调制：DMR 4FSK 频偏先做成根升余弦 `m(t)`，再量化成 `m_q`，然后同一条 `m_q` 同时送入片内 ΔΣ 小数分频 PLL（低频通路）和外部 VCO 的直接调制口（高频通路）。环路带宽两侧两条通路互补，相加后在 DMR 调制带宽内重建 `m_q`。

这不是晶体管网表。模型包含鉴相器、电荷泵、三阶环路滤波器、VCO、N 分频器和三阶 MASH ΣΔ 量化噪声。

## 数据手册里的两点调制

AK2404 自己集成 23 bit ΔΣ 小数 N 锁相环（第 13.7 节），外接环路滤波器和 VCO。

发射两点调制由手册第 9.6 节和第 13.9 节规定：

- `MODFS` / `MODSCLK` / `MODSDI` 每个帧写入 32 bit。`MODFS` 最高 96 kHz。
- **L 通道 16 bit**（二进制补码）写入 `OFS_MDLT`，进入 PLL 频率公式，是闭环低通通路。
- **H 通道 12 bit**（二进制补码）进入 `MODDAC`，经平滑滤波器 `SMF`（手册：Fc = 20 kHz）从 `MODOUT` 送到外部 VCO 的直接调制口，是高频通路。
- 第 13.9 节原文：MODDAC 用于 VCO 直接调制，并可与第 13.7.5 节的 PLL 调制组成两点调制。

VCO 输出回到 `LOINP` / `LOINN`。发射时本振分频器再把已调 VCO 分频，经驱动放大器从 `TXOUT` 输出（第 13.10 节）。本仿真的载波按手册 BAND1：射频 450 MHz，`DIVSEL = 2`，VCO = 900 MHz。450 MHz 落在 DMR UHF 12.5 kHz 栅格上，也在 N 分频器 100–1920 MHz 和工作频率 45–960 MHz 以内。

频率设定（式 13.1）和调制频偏（式 13.9）：

```
fVCO = fPFD * ( INT + FRAC/MOD + DEN_RATIO * (OFS_FINE + OFS_MDLT) / OFS_DEN )
ΔfVCO = fPFD * DEN_RATIO * OFS_MDLT / OFS_DEN
```

`DEN_RATIO` 用来补偿本振分频（1 / 2 / 4 / 8）。这里 `DEN_RATIO = DIV = 2`，所以 16 bit 频偏字按**射频**赫兹标定：`ΔfRF = fPFD * OFS_MDLT / OFS_DEN`。`OFS_DEN = 8388607`、`fPFD = 19.6608 MHz` 时，射频 LSB = `19660800 / 8388607` ≈ **2.34375 Hz**。仿真不用满 16 bit，只用高 12 bit，步长变成 16 倍，约 **37.500 Hz**。满幅仍是这只 16 bit 字的满幅：`q12 = −2048` 对应 `OFS_MDLT = −32768`，`q12 = 2047` 对应 `OFS_MDLT = 32752`。

## 信号链

```
随机比特（种子 2404）
    → DMR 双比特  01:+1944  00:+648  10:-648  11:-1944 Hz
    → 平方根升余弦（滚降 0.2，跨度 12 个符号，sps = 16）= m(t)
       采样率 16 × 4800 = 76800 Hz
    → 有符号 12 bit 量化（占满 16 bit OFS 字的高 12 bit），得到 m_q
         │
         ├─ L 通道  OFS_MDLT = q12 × 16 → MASH ΣΔ 整数 N
         │            → 鉴相器 / 电荷泵 / 三阶环路滤波器 → VCO 调谐口
         │            闭环对这条通路呈低通（约 1 kHz）
         │
         └─ H 通道  m_h = 预加重(m_q) → 12 bit MODDAC → SMF → MODOUT
                      → VCO 调制口（Km）
                      闭环把这条通路改造成高通
                              │
                    fRF(t) = fVCO(t) / 2
                    频偏应重建 m_q
```

量化在两条通路分开之前做完。`Km = 20 kHz/V`、`DIVSEL = 2`、MODDAC 满幅 `1.35 Vpp` 都没有改。

```
q16 = round(m * OFS_DEN / fPFD)
q12 = clamp(round(q16 / 16), -2048, 2047)
m_q = q12 * 16 * fPFD / OFS_DEN
L 通道 OFS_MDLT = q12 * 16          （不再滤波）
m_h = 预加重(m_q)                   （只给 H 通道）
H 通道 = clamp(round(m_h * DIVSEL / Km * 4096 / 1.35), -2048, 2047)
```

`±1944 Hz` 的常数电平：`q16 = ±829`，`q12 = ±52`，`OFS_MDLT = ±832`，`m_q = ±1950.00 Hz`。预加重的直流增益是 1，所以停在这个电平上时 `m_h` 也是 ±1950 Hz，H 通道码仍是 `±592`。`±648 Hz` 落到 `q12 = ±17`、`m_q = ±637.50 Hz`。因为 `q16` 先取整再除以 16，合成误差可以略大于半个 37.5 Hz 步长；400 个符号里 `|m − m_q|` 最大 **19.91 Hz**。

共用量化之后才分成两路。L 通道就是 `m_q`。H 通道先做数字预加重，再量化成原来的 12 bit MODDAC 码。环路带宽仍是约 1 kHz，相位裕量仍是 55°，这次没有改。互补关系变成 `H(s) + (1−H(s))·Gsmf(s)·Hpre(s)`。`Hpre` 在 DMR 频段里近似 `1/Gsmf`，所以高通支路在 SMF 之后回到 `m_q`。

### H 通道预加重

SMF 在 6 kHz 以内几乎没有幅度下降（3 kHz 和 6 kHz 都是 0.00 dB），但相位滞后大约 14.8° 和 30.3°。三阶逆滤波器的零点在 `z = −1`，奈奎斯特增益会冲到几十 dB 以上，所以不能直接取逆。这里用一个二阶超前网络，在大约 1–6 kHz 上对齐 `1/Gsmf` 的相位超前和那一点幅度提升，更高频的增益被极点托住。

模拟原型（直流增益 1，高频增益 `(fp/fz)^2`）：

```
Hpre(s) = (fp/fz)^2 * (s^2 + (wz/Qz) s + wz^2) / (s^2 + (wp/Qp) s + wp^2)
fz = 11.952 kHz，fp = 26.533 kHz，Qz = 0.801，Qp = 1.247
```

再在 76.8 kHz 上做双线性变换。名义高频增益 **+13.85 dB**。实际离散响应在 22.6 kHz 最高到 **+16.35 dB**，奈奎斯特是 **+13.85 dB**，不再随着三阶逆滤波器往上冲。

| 频率 | 预加重幅度 | 预加重相位 | 经过 SMF 之后 |
| --- | --- | --- | --- |
| 3 kHz | −0.030 dB | +13.32° | −0.030 dB，−1.49° |
| 6 kHz | +0.104 dB | +29.87° | +0.102 dB，−0.47° |

400 个符号里 H 通道码**没有削波**。稳定符号上 `|m_h|` 峰值 **3296 Hz**，和 `|m_q|` 的 3300 Hz 差不多，对应码约 ±1000，离满幅 2047（射频约 6747 Hz）还有 **6.2 dB**。调制从 6 ms 静默切进来的第一个样点会振到 **6055 Hz**、码 1837，离满幅还有 0.9 dB，这一下也不削波。环路带宽和相位裕量没有为这个滤波器改过。

每个 `MODFS` 周期（76.8 kHz）内恰好有 `19.6608 MHz / 76.8 kHz = 256` 个鉴相周期。ΣΔ 在鉴相速率上跑；作图用的频偏是这 256 拍的平均。

## 保真度限制

- 行为模型：三态鉴相器在 ±1 个参考周期内线性、超出后饱和；电荷泵是该相位误差乘以 ICP。没有电荷泵失配、死区、1/f 噪声，也没有把手册 −210 dBc/Hz 的归一化相位噪声注进 VCO。
- ΣΔ 量化在每一个鉴相周期都加到分频字上。三阶成形噪声被约 1 kHz 的环路压掉，所以 76.8 kHz 的频偏曲线上看不到它。
- 高于环路带宽的能量走 H 通道。SMF 在 3 kHz 大约滞后 15°。H 通道预加重把这段相位补上之后，相对 `m_q` 的偏差 RMS 从大约 195 Hz 降到大约 30 Hz。剩下的是 6 kHz 以外没有完全对上的相位、12 bit 台阶被预加重抬起来的边沿，以及环路和 SMF 的模型误差。手册没有规定这只预加重滤波器，零极点是按本仿真的 SMF 拟合的。
- L 通道 1.4 µs 的写入延迟和 H 通道十几个 `MODSCLK` 的延迟都没有插入。
- 快锁（`CPFAST`、环路开关）没有模拟；电流是正常档 `CPFINE`。
- Kvco、Km 取成常数。真实外部 VCO 的调谐曲线和调制口增益要按板子改 `params_ak2404_dmr.m`。
- 射频没有按 450 MHz 采样。输出是分频之后的瞬时频偏，以及由它生成的复基带包络谱。
- 根升余弦截断为 12 个符号，常数符号上约有 16 Hz 峰峰值纹波。

## FSK 误差和邻道功率

采样率、参考时钟、12 bit 共用量化和环路（约 1 kHz、55°）都没有改。这一档只在 H 通道、量化之后加了预加重。捕获 **400 个符号**、种子 2404。入口：

```bash
cd /workspace/dmr-2pt-synth
octave --no-gui --eval "measure_fsk_acpr"
```

统计窗口去掉根升余弦前后各 6 个符号。拟合仍是 τ、`f0`、单一增益 `k`，使 `f_meas − f0 − k·参考(t−τ)` 的 RMS 最小。`FSKerr = 100 × rms(残差) / rms(k·参考)`。符号时刻用同一组拟合，只在符号中心取样，`100 × rms(残差) / 1944 Hz`。

三组对比把 12 bit 台阶单独露出来：


|                | 参考            | 被测            |
| -------------- | ------------- | ------------- |
| 合成器对 `m(t)`    | 量化前的根升余弦      | 合成器射频频偏       |
| 合成器对 `m_q`     | 12 bit 量化后的命令 | 合成器射频频偏       |
| `m_q` 对 `m(t)` | 量化前的根升余弦      | `m_q` 本身的理想调频 |

### 和限值怎么比

ETSI TS 102 361-1 V2.7.1 **第 10.2.2.3 节**规定的是另一种测试：符号流 `+3 +3 −3 −3 …` 经过调制后，等效为 1.2 kHz 正弦调频，峰值频偏应为 `2 × 1944 = 2749 Hz`，限值 **2749 Hz ± 10%**（2474 Hz 到 3024 Hz）。解调器高通 ≤ 15 Hz、低通 ≥ 3 kHz，不去加重。这次没有改用那条测试序列，所以上面两个 RMS 百分比**不能**直接判成通过或失败该条款。

在 TS 102 361-1 正文里没有找到“FSK 误差不得超过 5%”这一条。5% 是测试仪的工程判据，例如 VIAVI 3900 手册 2.5.13.B.8：在一个 30 ms 时隙的符号点上，RMS 频偏误差相对频偏不超过 5%。那不是 ETSI 条款。按这个工程判据，合成器对 `m(t)` 的符号时刻是 0.99%，波形拟合是 1.44%，两者分母不同。

### ACPR（12.5 kHz）

用调制载波的复包络，不用 `m(t)` 的频谱。限值来自 **ETSI EN 300 113 V3.1.1 第 7.4.3 节**：12.5 / 20 / 25 kHz 信道间隔上，邻道和隔道功率都不得超过载波功率以下 **60.0 dB**（也不要求低于 0.2 µW）。方法在第 7.4.2 节和附录 C。表 3：12.5 kHz 时，靠近载波一侧的 −6 dB 点，邻道在载频 ±8.25 kHz，隔道在 ±20.75 kHz；必要带宽 8.5 kHz。附录 C 给的是选择性容限，不是一条唯一的冲激响应。这里用名义断点（相对被测信道中心：±3.0 kHz 处 2 dB，±4.25 kHz 处 6 dB，±5.5 kHz 处 26 dB，±9.5 kHz 处 90 dB，以外保持 90 dB）做频率加权。阻带被掩模钉在 90 dB，所以隔道结果靠近 −88 到 −90 dBc 时，只说明它落在掩模地板上。未量化的 `m(t)` 隔道靠近这个地板；12 bit 量化之后隔道明显高于地板，见下表。
