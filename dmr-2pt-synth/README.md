# AK2404 发射两点调制频率合成器仿真

用 Octave / MATLAB 做的**行为级**频率合成器仿真，对象是 AK2404（数据手册 220900015-E-04）的发射两点调制：同一条 DMR 4FSK 频偏波形 `m(t)` 同时送入片内 ΔΣ 小数分频 PLL（低频通路）和外部 VCO 的直接调制口（高频通路）。环路带宽两侧两条通路互补，相加后在 DMR 调制带宽内重建 `m(t)`。

这不是晶体管网表。模型包含鉴相器、电荷泵、三阶环路滤波器、VCO、N 分频器和三阶 MASH ΣΔ 量化噪声。

## 数据手册里的两点调制（没有外挂 AK2401）

AK2404 自己集成 23 bit ΔΣ 小数 N 锁相环（第 13.7 节），外接环路滤波器和 VCO。手册里 **AK2401A 只出现一次**：寄存器 3 线串口的快速时钟模式与 AK2401A 兼容。调制通路并不去驱动一颗独立的 AK2401。

发射两点调制由手册第 9.6 节和第 13.9 节规定：

- `MODFS` / `MODSCLK` / `MODSDI` 每个帧写入 32 bit。`MODFS` 最高 96 kHz。
- **L 通道 16 bit**（二进制补码）写入 `OFS_MDLT`，进入 PLL 频率公式，是闭环低通通路。
- **H 通道 12 bit**（二进制补码）进入 `MODDAC`，经平滑滤波器 `SMF`（手册：Fc = 20 kHz）从 `MODOUT` 送到外部 VCO 的直接调制口，是高频通路。
- 第 13.9 节原文：MODDAC 用于 VCO 直接调制，并可与第 13.7.5 节的 PLL 调制组成两点调制。

VCO 输出回到 `LOINP` / `LOINN`。发射时本振分频器再把已调 VCO 分频，经驱动放大器从 `TXOUT` 输出（第 13.10 节）。本仿真的载波按手册 BAND1：射频 450 MHz，`DIVSEL = 2`，VCO = 900 MHz。450 MHz 落在 DMR UHF 12.5 kHz 栅格上，也在 N 分频器 100–1920 MHz 和工作频率 45–960 MHz 以内。

频率设定（式 13.1）和调制频偏（式 13.9）：

```
fVCO = fPFD * ( INT + FRAC/MOD + DEN_RATIO * (OFS_FINE + OFS_MDLT) / OFS_DEN )
ΔfVCO = fPFD * DEN_RATIO * OFS_MDLT / OFS_DEN
```

`DEN_RATIO` 用来补偿本振分频（1 / 2 / 4 / 8）。这里 `DEN_RATIO = DIV = 2`，所以 16 bit 频偏字按**射频**赫兹标定：`ΔfRF = fPFD * OFS_MDLT / OFS_DEN`。`OFS_DEN = 8388607` 时射频 LSB ≈ 2.93 Hz。

## 信号链

```
随机比特（种子 2404）
    → DMR 双比特  01:+1944  00:+648  10:-648  11:-1944 Hz
    → 平方根升余弦（滚降 0.2，跨度 12 个符号）= m(t)
         │
         ├─ L 通道  OFS_MDLT → MASH ΣΔ 整数 N
         │            → 鉴相器 / 电荷泵 / 三阶环路滤波器 → VCO 调谐口
         │            闭环对这条通路呈低通（约 1 kHz）
         │
         └─ H 通道  12 bit MODDAC → SMF → MODOUT
                      → VCO 调制口（Km）
                      闭环把这条通路改造成高通
                              │
                    fRF(t) = fVCO(t) / 2
                    频偏应重建 m(t)
```

两条通路送入的是**同一条** `m(t)`，没有事先用数字滤波器把高低频切开。互补性来自锁相环本身：分频比调制的闭环传递函数是 `H(s)`，直接加在 VCO 上的频偏传递函数是 `1-H(s)`。`H + (1-H) = 1`。H 通道还要经过 SMF，所以实际是 `H(s) + (1-H(s))·Gsmf(s)`。

每个 `MODFS` 周期（96 kHz）内恰好有 `fPFD/96 kHz = 256` 个鉴相周期。ΣΔ 在鉴相速率上跑；作图用的频偏是这 256 拍的平均。

## 保真度限制

- 行为模型：三态鉴相器在 ±1 个参考周期内线性、超出后饱和；电荷泵是该相位误差乘以 ICP。没有电荷泵失配、死区、1/f 噪声，也没有把手册 −210 dBc/Hz 的归一化相位噪声注进 VCO。
- ΣΔ 量化在每一个鉴相周期都加到分频字上。三阶成形噪声被约 1 kHz 的环路压掉，所以 96 kHz 的频偏曲线上看不到它。图上的误差主要不是量化，而是 SMF。
- DMR 频谱有相当一部分高于 1 kHz 环路带宽，走 H 通道。SMF 在 3 kHz 附近已经有十度量级的相位滞后，因此 `H + (1−H)·Gsmf` 不是理想的 1。这是约 212 Hz RMS 误差的主要来源。手册没有给出可对消这个相位的数字预加重。
- L 通道 1.4 µs 的写入延迟和 H 通道十几个 `MODSCLK` 的延迟都没有插入。
- 快锁（`CPFAST`、环路开关）没有模拟；电流是正常档 `CPFINE`。
- Kvco、Km 取成常数。真实外部 VCO 的调谐曲线和调制口增益要按板子改 `params_ak2404_dmr.m`。
- 射频没有按 450 MHz 采样。输出是分频之后的瞬时频偏，以及由它生成的复基带包络谱。
- 根升余弦截断为 12 个符号，常数符号上约有 16 Hz 峰峰值纹波。

## FSK 误差和邻道功率

调制结构没有改。这条测量把捕获加长到 **400 个符号**（种子仍是 2404），只跑双通路合成器，用来和理想 `m(t)` 对比。入口：

```bash
cd /workspace/dmr-2pt-synth
octave --no-gui --eval "measure_fsk_acpr"
```

统计窗口去掉根升余弦前后各 6 个符号。**(A)** 是由 `m(t)` 直接做的理想调频；**(B)** 是合成器射频频偏（VCO 频率减去载波后再除以 2）。

### 1. 波形拟合

在已知符号生成的根升余弦参考 `m_ref` 上拟合符号定时 τ、频偏 `f0` 和单一增益 `k`，使 `f_meas − f0 − k·m_ref(t−τ)` 的 RMS 最小。

`FSKerr = 100 × rms(残差) / rms(k·m_ref)`。

| | FSKerr | f0 | k | τ |
| --- | --- | --- | --- | --- |
| A 理想调频 | 0.000% | 0 Hz | 1.000000 | 0 µs |
| B 合成器 | 5.353% | 3.36 Hz | 1.06387 | 14.06 µs |

`k = 1.064` 表示拟合把合成器频偏整体缩小了约 6.4% 之后，剩下的形状误差仍有 5.35%。理想一路拟合回到零，说明公式和定时搜索没有把零误差测成别的数。

### 2. 符号时刻（按 1944 Hz 归一）

用上面的 τ、`f0`、`k`，只在拟合后的符号中心取样，残差相对外层符号频偏 1944 Hz：

`100 × rms(残差) / 1944 Hz`。

| | 符号时刻误差 | 残差 RMS |
| --- | --- | --- |
| A 理想调频 | 0.000% | 0 Hz |
| B 合成器 | 4.035% | 78.4 Hz |

### 和限值怎么比

ETSI TS 102 361-1 V2.7.1 **第 10.2.2.3 节**规定的是另一种测试：符号流 `+3 +3 −3 −3 …` 经过调制后，等效为 1.2 kHz 正弦调频，峰值频偏应为 `2 × 1944 = 2749 Hz`，限值 **2749 Hz ± 10%**（2474 Hz 到 3024 Hz）。解调器高通 ≤ 15 Hz、低通 ≥ 3 kHz，不去加重。这次没有改用那条测试序列，所以上面两个 RMS 百分比**不能**直接判成通过或失败该条款。

在 TS 102 361-1 正文里没有找到“FSK 误差不得超过 5%”这一条。5% 是测试仪的工程判据，例如 VIAVI 3900 手册 2.5.13.B.8：在一个 30 ms 时隙的符号点上，RMS 频偏误差相对频偏不超过 5%。那不是 ETSI 条款。按这个工程判据，合成器的符号时刻结果是 4.03%，波形拟合结果是 5.35%，两者分母不同，不能混成同一个 5%。

### ACPR（12.5 kHz）

用调制载波的复包络，不用 `m(t)` 的频谱。限值来自 **ETSI EN 300 113 V3.1.1 第 7.4.3 节**：12.5 / 20 / 25 kHz 信道间隔上，邻道和隔道功率都不得超过载波功率以下 **60.0 dB**（也不要求低于 0.2 µW）。方法在第 7.4.2 节和附录 C。表 3：12.5 kHz 时，靠近载波一侧的 −6 dB 点，邻道在载频 ±8.25 kHz，隔道在 ±20.75 kHz；必要带宽 8.5 kHz。附录 C 给的是选择性容限，不是一条唯一的冲激响应。这里用名义断点（相对被测信道中心：±3.0 kHz 处 2 dB，±4.25 kHz 处 6 dB，±5.5 kHz 处 26 dB，±9.5 kHz 处 90 dB，以外保持 90 dB）做频率加权。阻带被掩模钉在 90 dB，所以隔道结果靠近 −88 到 −90 dBc 时，只说明它落在掩模地板上。
